========================================
QUICK SITEMAP CRON SETUP - 5 MINUTES
========================================

WHAT THIS DOES:
✅ Auto-generates sitemap.xml every 6 hours
✅ Includes all 13 static pages + all active short links
✅ Google indexes your short URLs automatically
✅ Higher priority for popular links (more clicks)

========================================
STEP 1: UPLOAD FILES
========================================

Upload these 2 files to Hostinger:

1. app/Console/Commands/GenerateSitemap.php (NEW FILE)
   → /public_html/shortenn_laravel/app/Console/Commands/GenerateSitemap.php

2. routes/console.php (MODIFIED FILE)
   → /public_html/shortenn_laravel/routes/console.php

========================================
STEP 2: TEST MANUALLY (SSH)
========================================

Login to SSH and run:

cd /home/u824503943/domains/shortenn.org/public_html/shortenn_laravel
php artisan sitemap:generate

Expected output:
"Sitemap generated successfully!"
"Total static pages: 13"
"Total short links: [number]"

Test in browser:
https://shortenn.org/sitemap.xml

========================================
STEP 3: SETUP CRON JOB (hPanel)
========================================

1. Login to Hostinger hPanel
2. Go to: Advanced → Cron Jobs
3. Click: Create Cron Job
4. Enter:

   Common Settings: Custom
   Minute: 0
   Hour: */6
   Day: *
   Month: *
   Weekday: *

   Command:
   cd /home/u824503943/domains/shortenn.org/public_html/shortenn_laravel && /usr/bin/php artisan schedule:run >> /dev/null 2>&1

5. Click: Create

RUNS: Every 6 hours (00:00, 06:00, 12:00, 18:00)

========================================
STEP 4: SUBMIT TO GOOGLE
========================================

1. Go to: https://search.google.com/search-console
2. Select: shortenn.org
3. Go to: Sitemaps (left sidebar)
4. Add: https://shortenn.org/sitemap.xml
5. Click: Submit

Google will:
- Index all your short links
- Re-crawl every few days
- Show stats in Search Console

========================================
WHAT GETS INCLUDED
========================================

Static Pages (13):
- Homepage, About, Features, FAQ
- Guide (NEW!), Privacy, Terms
- Login, Register, etc.

Short Links (up to 10,000):
- Only ACTIVE links
- Not expired
- Within click limits
- Ordered by popularity

Priority System:
- 1000+ clicks → 0.7 priority
- 500+ clicks → 0.6 priority
- 100+ clicks → 0.5 priority
- 50+ clicks → 0.4 priority
- Less → 0.3 priority

========================================
TROUBLESHOOTING
========================================

Sitemap not generating?
→ Run manually: php artisan sitemap:generate
→ Check logs: storage/logs/laravel.log

Permission denied?
→ chmod 755 /public_html/
→ chmod 644 /public_html/sitemap.xml

Command not found?
→ php artisan cache:clear
→ php artisan config:clear
