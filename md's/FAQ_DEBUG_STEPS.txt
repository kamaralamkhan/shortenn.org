========================================
FAQ WHITE PAGE - DEBUGGING STEPS
========================================

You've uploaded:
✅ app.blade.php (layout)
✅ faq.blade.php (content)

But still seeing white page.

========================================
STEP 1: CHECK LARAVEL LOGS
========================================

Via SSH or File Manager, check:
/public_html/shortenn_laravel/storage/logs/laravel.log

Look at the LAST 50 lines for errors.

Via SSH:
tail -n 50 /home/u824503943/domains/shortenn.org/public_html/shortenn_laravel/storage/logs/laravel.log

Look for:
- Syntax errors
- View not found
- Blade compilation errors
- Any PHP errors

========================================
STEP 2: CLEAR ALL CACHES (AGAIN)
========================================

Via SSH, run THESE EXACT COMMANDS:

cd /home/u824503943/domains/shortenn.org/public_html/shortenn_laravel

# Delete compiled views
rm -rf storage/framework/views/*

# Delete bootstrap cache
rm -f bootstrap/cache/config.php
rm -f bootstrap/cache/routes-v7.php
rm -f bootstrap/cache/services.php
rm -f bootstrap/cache/packages.php

# Clear Laravel caches
php artisan cache:clear
php artisan view:clear
php artisan config:clear
php artisan route:clear

========================================
STEP 3: CHECK FILE EXISTS ON SERVER
========================================

Via SSH or File Manager, verify:

ls -lh /home/u824503943/domains/shortenn.org/public_html/shortenn_laravel/resources/views/pages/faq.blade.php

Should show:
- File exists
- Size is around 5,000 bytes (NOT 0 bytes!)

If 0 bytes or missing, upload again!

========================================
STEP 4: CHECK FILE PERMISSIONS
========================================

Via SSH:

chmod 644 /home/u824503943/domains/shortenn.org/public_html/shortenn_laravel/resources/views/pages/faq.blade.php

chmod 755 /home/u824503943/domains/shortenn.org/public_html/shortenn_laravel/storage/framework/views/

========================================
MOST LIKELY CAUSES:
========================================

1. ❌ Compiled view cache not cleared
   → Delete storage/framework/views/*

2. ❌ File uploaded to wrong location
   → Verify exact path on server

3. ❌ File is still 0 bytes on server
   → Re-upload the file

4. ❌ PHP syntax error in faq.blade.php
   → Check laravel.log for error

5. ❌ Layout (app.blade.php) has syntax error
   → Check laravel.log for error
